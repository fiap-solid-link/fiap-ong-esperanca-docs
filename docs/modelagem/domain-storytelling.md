## O que é Domain Storytelling?

**Domain Storytelling** é uma técnica colaborativa de modelagem de domínio onde especialistas de negócio narram como o trabalho é feito, usando uma notação pictográfica simples. O objetivo é capturar o fluxo de trabalho do ponto de vista dos atores, tornando o conhecimento de domínio explícito e compartilhado entre times técnicos e de negócio.
